# Workflow Fieldbook lab

Start in the repository root. All public inputs describe the fictional north-store dealership for September 2026. Identify the entity, reporting period, currency and source references in any financial draft.

Use the fieldbook MCP tool for a verified packet. Preserve the threshold verdict and signed variance. Keep open pipeline separate from recognized income. Mark proposed explanations as questions when the packet lacks supporting detail. A missing source, entity mismatch, period mismatch or tool failure ends the reporting attempt.

The controller reviews a draft before distribution. Report status and open questions in the response. For a new session, hand over the accepted packet reference, policy version, unresolved question and named reviewer. Keep client records in the private workspace assigned to that entity.
